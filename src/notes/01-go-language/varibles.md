# varibles

## 变量声明

使用 `var` 关键字声明变量，类型写在变量名后面。

```go
var i int
var c, python, java bool
```

可在包级或函数内声明。带初始化值时，类型可省略（由初始化值决定类型）：

```go
var i, j int = 1, 2
var c, python, java = true, false, "no!"
```

也可用括号将多个声明合并：

```go
var (
    ToBe   bool       = false
    MaxInt uint64     = 1<<64 - 1
)
```

## 类型推断

声明时不写类型，编译器根据右侧初始化值自动推断类型。

- 使用 `var =` 或 `:=` 均可触发类型推断。
- 右侧是已有类型的值时，新变量获得相同类型：
  ```go
  var i int
  j := i  // j 的类型为 int
  ```
- 右侧是未类型化的数字常量时，根据精度推断为 `int`、`float64` 或 `complex128`：
  ```go
  i := 42           // int
  f := 3.142        // float64
  g := 0.867 + 0.5i // complex128
  ```

## 自动零值

变量声明后若未显式初始化，会被自动赋予该类型的零值。

常见零值：
- 数值类型（int、float 等）：`0`
- 布尔类型：`false`
- 字符串：`""`（空字符串）
- 指针、切片、映射、通道、函数、接口：`nil`

零值设计使得变量声明后即可安全使用，无需额外初始化。

## 变量简写

在函数内部，可用 `:=` 进行短变量声明（同时声明并初始化，并自动推断类型）。

```go
k := 3
c, python, java := true, false, "no!"
```

注意：
- `:=` 只能在函数内部使用。
- 包级变量必须使用完整的 `var` 声明。
- `:=` 至少要声明一个新变量；如果所有变量都已存在，则变成普通赋值（需用 `=`）。

## 多变量声明

可一次声明多个变量：

```go
// 相同类型
var x, y, z int

// 带初始化（类型可省略）
var a, b, c = 1, 2, "three"

// 短声明
i, j := 0, 10
r, w, _ := os.Pipe()  // 忽略不需要的返回值
```

短声明允许“重声明”：同一作用域内，只要至少有一个变量是新的，已存在的变量会被重新赋值（类型必须兼容）。这是 Go 中处理 `err` 等常见模式的基础。
