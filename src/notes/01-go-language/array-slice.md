# array-slice

## **数组**

数组类型定义指定了长度和元素类型。例如，类型 `[4]int` 表示包含四个整数的数组。数组的大小是固定的；其长度是类型的一部分（`[4]int` 和 `[5]int` 是不同的、不兼容的类型）。数组可以按通常方式索引，表达式 `s[n]` 访问从零开始的第 n 个元素。

### 读写数组

```go
var a [4]int
a[0] = 1
i := a[0]
// i == 1
```

数组字面量可以这样指定：

```go
b := [2]string{"Penn", "Teller"}
```

或者让编译器计算元素个数：

```go
b := [...]string{"Penn", "Teller"}
```

在这两种情况下，`b` 的类型都是 `[2]string`。

来自 A Tour of Go 的示例：

```go
package main

import "fmt"

func main() {
    var a [2]string
    a[0] = "Hello"
    a[1] = "World"
    fmt.Println(a[0], a[1])
    fmt.Println(a)

    primes := [6]int{2, 3, 5, 7, 11, 13}
    fmt.Println(primes)
}
```

数组不需要显式初始化；数组的零值是一个就绪可用的数组，其元素本身为零值。

### 获取长度

数组的长度是其类型的一部分，且永远不会为负。使用内置函数 `len` 可获取数组长度。对于数组，`len` 返回元素个数。

## **切片**

切片类型是建立在 Go 数组类型之上的抽象。切片类型规范为 `[]T`，其中 `T` 是切片元素的类型。与数组类型不同，切片类型没有指定的长度。

切片字面量的声明方式与数组字面量相同，只是省略元素计数：

```go
letters := []string{"a", "b", "c", "d"}
```

切片也可以用内置函数 `make` 创建，其签名为：

```go
func make([]T, len, cap) []T
```

`make` 接受类型、长度以及可选的容量。调用时，`make` 分配一个数组并返回引用该数组的切片。当省略容量参数时，它默认为指定的长度。

```go
s := make([]byte, 5)
// s == []byte{0, 0, 0, 0, 0}
len(s) == 5
cap(s) == 5
```

切片的零值是 `nil`。对于 nil 切片，`len` 和 `cap` 函数都返回 0。

### 读写元素

切片通过指定由冒号分隔的半开区间的两个索引来形成：

```go
a[low : high]
```

这选择一个半开范围，包含第一个元素，但不包含最后一个元素。以下表达式创建包含 `a` 的元素 1 到 3 的切片：

```go
a[1:4]
```

示例（来自 A Tour of Go）：

```go
package main

import "fmt"

func main() {
    primes := [6]int{2, 3, 5, 7, 11, 13}
    var s []int = primes[1:4]
    fmt.Println(s)
}
```

切片不存储任何数据，它只描述底层数组的一个段。更改切片的元素会修改其底层数组的相应元素。共享同一底层数组的其他切片也会看到这些更改。

示例：

```go
package main

import "fmt"

func main() {
    names := [4]string{
        "John",
        "Paul",
        "George",
        "Ringo",
    }
    fmt.Println(names)

    a := names[0:2]
    b := names[1:3]
    fmt.Println(a, b)

    b[0] = "XXX"
    fmt.Println(a, b)
    fmt.Println(names)
}
```

### 长度与容量

切片同时具有长度和容量。切片的长度是它所包含的元素数量。切片的容量是底层数组中从切片第一个元素开始计数的元素数量。切片 `s` 的长度和容量可通过表达式 `len(s)` 和 `cap(s)` 获得。

只要有足够的容量，就可以通过重新切片来扩展切片的长度。

示例（来自 A Tour of Go）：

```go
package main

import "fmt"

func main() {
    s := []int{2, 3, 5, 7, 11, 13}
    printSlice(s)

    // 将切片切片以使其长度为 0。
    s = s[:0]
    printSlice(s)

    // 扩展其长度。
    s = s[:4]
    printSlice(s)

    // 丢弃其前两个值。
    s = s[2:]
    printSlice(s)
}

func printSlice(s []int) {
    fmt.Printf("len=%d cap=%d %v\n", len(s), cap(s), s)
}
```

### 切片截取

切片通过指定半开范围的两个索引（用冒号分隔）来完成。例如，表达式 `b[1:4]` 创建一个包含 `b` 的元素 1 到 3 的切片（结果切片的索引将是 0 到 2）。

```go
b := []byte{'g', 'o', 'l', 'a', 'n', 'g'}
// b[1:4] == []byte{'o', 'l', 'a'}，与 b 共享相同的存储
```

切片表达式的起始和结束索引是可选的；它们分别默认为零和切片的长度：

```go
// b[:2] == []byte{'g', 'o'}
// b[2:] == []byte{'l', 'a', 'n', 'g'}
// b[:] == b
```

这也是给定数组创建切片的语法：

```go
x := [3]string{"Лайка", "Белка", "Стрелка"}
s := x[:] // 引用 x 存储的切片
```

切片操作不会复制切片的数据。它创建一个指向原始数组的新切片值。因此，修改重新切片的元素（而不是切片本身）会修改原始切片的元素。

### 追加元素

内置函数 `append` 将元素追加到切片的末尾，并在需要更大容量时增长切片。其签名为：

```go
func append(s []T, x ...T) []T
```

```go
a := make([]int, 1)
// a == []int{0}
a = append(a, 1, 2, 3)
// a == []int{0, 1, 2, 3}
```

要将一个切片追加到另一个切片，使用 `...` 将第二个参数展开为参数列表。

```go
a := []string{"John", "Paul"}
b := []string{"George", "Ringo", "Pete"}
a = append(a, b...) // 等价于 "append(a, b[0], b[1], b[2])"
// a == []string{"John", "Paul", "George", "Ringo", "Pete"}
```

由于切片的零值（`nil`）的行为类似于零长度切片，可以声明一个切片变量，然后在循环中向其追加：

```go
// Filter 返回一个新切片，仅包含 s 中满足 fn() 的元素
func Filter(s []int, fn func(int) bool) []int {
    var p []int // == nil
    for _, v := range s {
        if fn(v) {
            p = append(p, v)
        }
    }
    return p
}
```

**数组与切片的对比**

数组的大小是固定的；其长度是类型的一部分。数组是值。赋值一个数组到另一个会复制所有元素。如果将数组传递给函数，它将接收数组的副本，而不是指向它的指针。

切片是对数组元素的动态大小的灵活视图。在实践中，切片比数组常见得多。切片类型没有指定的长度。切片是数组段的描述符。它由指向数组的指针、段的长度及其容量（段的最大长度）组成。切片持有对底层数组的引用；如果将一个切片赋值给另一个，两者都引用同一个数组。如果函数接受切片参数，它对切片元素所做的更改对调用者可见，类似于传递底层数组的指针。

切片构建在数组之上，以提供强大和便利。除了具有显式维度的项目（如变换矩阵）外，Go 中的大多数数组编程都使用切片而不是简单的数组。
