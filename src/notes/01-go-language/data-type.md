# data-type


Go 是静态强类型语言，所有变量在编译时都必须有明确类型。Go 的类型系统由**预声明基本类型**和**复合类型**组成。预声明基本类型包括布尔、数字和字符串；复合类型包括数组、切片、映射、结构体、接口、指针、函数和通道等。数据类型。

## 字符串

```
package main

import "fmt"

func main() {
	text := "这是一段文本，苍天已死，黄天当立，岁在甲子，天下大吉。"
    text += "\n这是第二段文本，天地玄黄，宇宙洪荒，日月盈昃，辰宿列张。"
	fmt.Println(text)
}

```

`string` 是 Go 的预声明类型，表示一个（可能为空的）字节序列。字符串的长度永远非负，用内置函数 `len` 可获取其字节数。

字符串是**不可变**的：一旦创建，内容无法修改。字符串值通常表示 UTF-8 编码的文本，但并不强制要求必须是合法的 UTF-8。字符串可以包含任意字节，包括零字节。

零值为空字符串 `""`。

字符串支持索引操作（得到的是 `byte`）、切片操作（得到新字符串），以及通过 `range` 按 Unicode 码点（`rune`）遍历。字符串字面量可用双引号 `""` 或反引号 `` ` ``（原始字符串字面量，可跨行且不解释转义）。

`byte` 是 `uint8` 的别名，常用于表示字符串中的单个字节；`rune` 是 `int32` 的别名，常用于表示 Unicode 码点。

## 数字


Go 提供多种预声明的数字类型，分为整数、浮点数和复数三大类。

```
package main

import "fmt"

func main() {
	var age int = 18
	fmt.Println(age)
}

```
**整数类型**（架构无关的固定宽度）：
- 有符号：`int8`、`int16`、`int32`、`int64`
- 无符号：`uint8`、`uint16`、`uint32`、`uint64`

此外还有：
- `int`：有符号整数，大小至少 32 位，在 32 位系统上通常为 32 位，在 64 位系统上通常为 64 位。
- `uint`：无符号整数，大小规则与 `int` 相同。
- `uintptr`：无符号整数，大小足以容纳任意指针的位模式。

`byte` 是 `uint8` 的别名，`rune` 是 `int32` 的别名。

**浮点类型**：
- `float32`：IEEE 754 32 位浮点数
- `float64`：IEEE 754 64 位浮点数

**复数类型**：
- `complex64`：由两个 `float32` 组成的复数
- `complex128`：由两个 `float64` 组成的复数

不同数字类型之间不能隐式转换，必须显式转换。无类型常量（untyped constant）在赋值或运算时会根据上下文自动获得合适的类型。零值均为 `0`（复数的实部和虚部都为 `0`）。


## 布尔

```
package main

import "fmt"

func main() {
	var isShow bool = true
	fmt.Println(isShow)
}

```

`bool` 是预声明的布尔类型，表示逻辑真值，只有两个值：`true` 和 `false`。

零值为 `false`。布尔值不能与数字进行隐式转换，必须显式处理。

布尔类型主要用于条件判断、逻辑运算（`&&`、`||`、`!`）以及比较表达式的结果。

## 数组和切片

```
package main

import "fmt"

func main() {
	//数组
	var arr [5]int // 定义一个长度为5的整型数组 但是未赋值 所以输出为[0 0 0 0 0]
	fmt.Println(arr)
	//----------------------------------------------------------------------
	arr2 := [5]int{1, 2, 3, 4, 5} // 定义一个长度为5的整型数组 并赋值为[1 2 3 4 5]
	fmt.Println(arr2)
	//----------------------------------------------------------------------
	//切片
	arr3 := []int{}                          // 定义一个空切片
	arr3 = append(arr3, 6, 6, 6, 6, 6, 6, 6) // 追加元素
	fmt.Println(arr3)                        // 输出为[6 6 6 6 6 6 6]
	fmt.Println(len(arr3))                   // 获取切片的长度 输出为7
}

```

**数组（Array）** 是固定长度的、同类型元素的有序序列。数组长度是类型的一部分，因此 `[3]int` 和 `[4]int` 是不同的类型。长度永远非负，可通过 `len` 获取。

数组是值类型，赋值或传参时会复制整个数组。零值是所有元素都为对应类型零值的数组。

数组字面量可用 `...` 让编译器自动计算长度。

**切片（Slice）** 是对底层数组连续段的描述符，提供可变长度的视图。切片类型写作 `[]T`，其中 `T` 是元素类型。

切片包含三个属性：
- 指向底层数组的指针
- 长度（`len`）
- 容量（`cap`，从切片起始位置到底层数组末尾的最大长度）

未初始化的切片值为 `nil`，`len` 和 `cap` 均为 0。可用 `make` 创建指定长度和容量的切片，也可用切片字面量或从数组/切片再切片得到。

切片是引用类型（更准确地说是描述符），多个切片可共享同一底层数组，修改一个会影响其他。内置函数 `append` 用于向切片追加元素（必要时会分配新底层数组），`copy` 用于在切片间复制元素。

切片是 Go 中最常用的序列类型，推荐优先使用切片而非数组。

## 映射

```
package main

import "fmt"

func main() {
	// 定义一个 map，键为 string，值为 int
	scores := map[string]int{
		"张三": 90,
		"李四": 85,
		"王五": 92,
	}
	fmt.Println(scores["张三"]) // 输出：90

	// 添加或修改键值对
	scores["赵六"] = 88
	delete(scores, "李四") // 删除键值对

	// 判断键是否存在
	score, ok := scores["张三"]
	if ok {
		fmt.Println("张三的分数是", score)
	}
}

```

映射（Map）是无序的键值对集合，写作 `map[KeyType]ElementType`。键类型必须支持比较（`==` 和 `!=`），不能是函数、映射或切片。

未初始化的映射值为 `nil`。对 `nil` 映射进行读写会 panic（读取返回零值，写入会 panic）。必须用 `make` 或映射字面量创建后才能写入。

`len` 返回当前元素个数。用 `delete` 删除指定键的元素。通过两值赋值可判断键是否存在：`value, ok := m[key]`。

映射的零值是 `nil`。映射是引用类型，赋值或传参不会复制内部数据。

## 结构体

```
package main

import "fmt"

// 定义结构体类型
type Person struct {
	Name string
	Age  int
}

func main() {
	// 创建结构体实例
	p := Person{
		Name: "小满",
		Age:  18,
	}
	fmt.Println(p.Name, p.Age) // 输出：小满 18

	// 访问和修改字段
	p.Age = 20
	fmt.Println(p.Age) // 输出：20
}

```

结构体（Struct）是命名字段的序列，每个字段有名字和类型。结构体类型写作：

```go
struct {
    Field1 Type1
    Field2 Type2
    // ...
}
```

字段可以显式命名，也可以是嵌入字段（Embedded Field，实现组合）。字段可以带标签（tag，字符串字面量），常用于反射或序列化。

结构体是值类型，赋值和传参会复制整个结构体。零值是所有字段都为对应零值的结构体。

结构体字面量可用按位置初始化或按字段名初始化。通过点操作符访问字段。可以给结构体类型定义方法。

结构体常用于组织相关数据，是 Go 中实现数据封装的主要方式。

## 接口

```
package main

import "fmt"

// 定义接口：包含一个 Speak 方法
type Animal interface {
	Speak() string
}

type Dog struct{}
type Cat struct{}

func (d Dog) Speak() string { return "汪汪" }
func (c Cat) Speak() string  { return "喵喵" }

func main() {
	var a Animal

	a = Dog{}
	fmt.Println(a.Speak()) // 输出：汪汪

	a = Cat{}
	fmt.Println(a.Speak()) // 输出：喵喵
}

```

接口（Interface）定义了一个**类型集合（type set）**。接口类型的变量可以存储该类型集合中任意类型的值。实现接口的类型称为“实现了该接口”。

最简单的接口是空接口 `interface{}`（Go 1.18 起别名为 `any`），它的类型集合包含所有类型。

接口通常声明一组方法签名。一个类型只要拥有接口要求的所有方法（方法集匹配），就隐式实现了该接口，无需显式声明。

未初始化的接口值为 `nil`。接口值内部包含动态类型和动态值。可通过类型断言 `x.(T)` 或类型开关（type switch）获取动态类型和值。

Go 1.18 起，接口还可用于定义类型约束（用于泛型），支持类型联合、近似元素（`~T`）等。`comparable` 是预声明的约束接口，表示所有可比较的类型。

接口是 Go 实现多态和抽象的核心机制，鼓励面向接口编程。
