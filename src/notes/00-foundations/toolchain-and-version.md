# toolchain-and-version

## Golang工具链

从 Go 1.21 开始，Go 发行版由 go 命令和捆绑的 Go 工具链组成。

**工具链包含标准库、编译器（gc）、汇编器、链接器以及其他相关工具。** go 命令不仅可以运行自己捆绑的工具链，还可以使用本地 PATH 中找到的其他版本，或按需自动下载所需版本。

工具链详细内容在: 官方文档（https://go.dev/doc/toolchain）

## Go 版本变化与发展历史

Go 由 Google 的 Robert Griesemer、Rob Pike 和 Ken Thompson 等人设计，2009 年 11 月 10 日开源发布。早期以每周或每月发布为主，2012 年 3 月 28 日正式发布 Go 1.0，确立了“Go 1 兼容性承诺”——在 Go 1 系列内保持向后兼容，保证大多数程序无需修改即可继续编译运行。

### 早期重要里程碑包括：

- Go 1.0（2012）奠定基础。
- Go 1.5（2015）实现了用 Go 重写编译器的自举，摆脱了对 C 编译器的依赖（之前 1.4 及更早需要 C 工具链）。
- Go 1.11（2018 年 8 月）实验性引入了 Modules（模块系统），解决依赖管理和版本控制问题，同时支持 GOPATH 模式。
- Go 1.13（2019）进一步改进模块支持，并默认使用模块代理和校验和数据库。
- Go 1.16（2021 年 2 月）将模块模式设为默认，并开始逐步弱化 GOPATH。
- Go 1.18（2022 年 3 月）正式加入泛型（generics）、工作区模式（workspaces，通过 go.work 管理多模块开发）、原生模糊测试（fuzzing）等重大特性。
- Go 1.21（2023 年 8 月）引入了工具链管理机制和前向兼容性强化：go 行变为强制最低版本要求，go 命令可自动下载并切换工具链，极大简化了多版本协作。同时完善了可重现构建。
- 后续版本持续在语言、运行时、标准库和工具上演进。例如 Go 1.22 改进了循环变量语义和整数 range；Go 1.23/1.24 引入并完善迭代器相关支持；较新版本（如 1.25、1.26、1.27）进一步优化垃圾回收（包括实验性 Green Tea GC 并默认启用）、支持泛型方法、增强 new 内置函数、改进测试包（如 synctest）、重写 go fix 命令以应用现代化建议，以及多项性能、安全和标准库增强。
